
# Examples

This directory contains several usage patterns and examples for the Sailfish Python package.
The examples are orgnaized into simple and advanced use cases.

examples are divided into four categories:

- **Simple**: These examples demonstrate basic usage of the Sailfish package, including simple simulations and basic configurations.

- **Advanced**: These examples showcase more complex scenarios, including advanced configurations, custom models, and integration with other tools.
    - Partition models.
    - Mixture models.
    - Clade specific models.

- **Phylogenetics applications**: These examples demonstrate how to use Sailfish in the context of phylogenetic research, including tree inference, model selection, and evolutionary analysis.
    - Parametric boostrapping.
    - Ancestral sequence reconstruction.
    - Phylogenetic tree inference.
